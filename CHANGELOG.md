# Changelog

## 1.0.0 — Zero-Assumption Development toolkit

Prepared on 14 October 2026. This entry describes the renamed toolkit, not a tagged GitHub release.

- Adopted Zero-Assumption Development (ZAD) as the name for Marcel Silva's proposed workflow.
- Made the starting point explicit: check whether the developer and AI understand the task before committing to a solution.
- Clarified that "zero-assumption" means not treating unchecked assumptions as facts, rather than ignoring established context or requiring absolute certainty.
- Retained question-based developer prompts, normal AI responses, selective clarification, scoped implementation, and evidence-based validation.
- Updated the agreement, manifesto, integrations, examples, templates, repository references, and script filenames for ZAD.
- Kept public Python class and function names unchanged. Updated script file suffixes to V2; the methodology version remains 1.0.0.
- Held README files outside the publication pending maintainer review. The new repository's existing README and MIT licence are unchanged.

No controlled comparative study is included. No tagged release or social announcement is part of this publication step.
